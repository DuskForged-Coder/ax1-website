A QUIETER KIND OF AI / 03

Private work
feels different.

AX1 is designed to run with local model runtimes. Your prompts go to the model on your computer when local inference is selected. No account is required for the local workflow.

Runtime and model downloads require an internet connection. The current desktop setup uses Ollama; setup screens should identify this clearly and show what will be installed.

START WITH MINI / 04

Make room for
good ideas.

AX1 Mini can be installed from the project source today. A signed consumer installer is a separate release step and is not available yet.

01

Prepare your computer

Use macOS or Windows with Python 3.10 or newer. Leave enough free disk space for the model you choose.

02

Open the AX1 source folder

In Terminal, go to the provided source checkout and enter AX1-Intelligence.

03

Install the desktop app

python3 -m pip install -e "[desktop]"
04

Launch AX1 Mini

ax1-desktop

Choose local runtime setup and review the Ollama and model download details. AX1 currently offers a fixed model list; hardware-based model recommendations are planned.
