START WITH MINI / 04

Make room for
good ideas.

AX1 Mini is a command-line product. Choose your operating system for the CLI setup commands. A graphical desktop client is a future direction.

Before you start: these commands need an authorized AX1 source checkout and must be run from its AX1-Intelligence folder. AX1 source and signed CLI installers are not currently available as public downloads on this site.

Windows 10 or newer · Python 3.10+ from python.org

01

Create an isolated environment

py -3 -m venv .venv
02

Install AX1 Mini CLI

.\.venv\Scripts\python.exe -m pip install -e .
03

Start AX1 Mini

.\.venv\Scripts\ax1.exe

macOS · Python 3.10+ · Apple Silicon or Intel

01

Create an isolated environment

python3 -m venv .venv
02

Install AX1 Mini CLI

.venv/bin/python -m pip install -e .
03

Start AX1 Mini

.venv/bin/ax1

64-bit Linux · Python 3.10+

01

Create an isolated environment

python3 -m venv .venv
02

Install AX1 Mini CLI

.venv/bin/python -m pip install -e .
03

Start AX1 Mini

.venv/bin/ax1

AX1 runs in your terminal. Model providers and runtime components are configured separately; no single third-party runtime is required by these CLI install steps.

Model availability, hardware fit, ownership, and licensing vary by model and provider.
